ROLE AND OBJECTIVE
Do not implement a broad collaboration suite. Use beta evidence to decide whether a narrow client-review loop—shareable review link, comments, approvals, or approval history—would materially improve retention and willingness to pay for freelancers/boutique agencies.
RESEARCH TASK
Interview at least 5 target users who exported or completed a campaign. Map how they currently collect client feedback and where campaign coherence breaks.
Quantify how often review is external, number of reviewers, sensitivity of assets, need for authentication/expiry, and whether approval history is legally or operationally important.
Compare three options: no collaboration; read-only expiring review link; authenticated comments/approval history. Evaluate value, privacy, abuse, support, data model, and pricing impact.
DELIVERABLE
Write a decision record with evidence, chosen/non-chosen options, smallest viable scope, security model, success metric, rollout flag, migration/rollback plan, and explicit no-go criteria.
If evidence is weak, choose no build and list smaller workflow improvements. Do not turn customer requests into an automatic roadmap commitment.
If approved, produce a separate implementation plan; do not add collaboration code in this prompt.
ACCEPTANCE CRITERIA
Decision cites real pilot evidence and analytics rather than intuition.
No unauthenticated data exposure is proposed without expiry, revocation, access controls, audit, and abuse considerations.
The core launch is not delayed for speculative scope.
FINAL REPORT
Return: (1) exact files changed, (2) behavior before and after, (3) tests run with exact pass/fail counts, (4) commands not run and why, (5) residual risks, (6) documentation/evidence updated, and (7) whether the next prompt is safe to start.
Use PASS only for a command or production observation that actually ran against the stated commit and environment. Use BLOCKED, NOT RUN, or FAILED otherwise.
Do not claim launch readiness in prose. Report evidence; the repository's release gate and the owner determine the verdict.
